\subsubsection{Two-dimensional correction maps}
The central and accompanying uncertainty maps are presented for all three channels. White regions in same-flavour maps lie above the ordered-lepton diagonal and are not physical correction bins. The mixed-flavour map has no such ordering restriction. The associated uncertainty image is labelled here as a supplied uncertainty map: whether its entries are absolute or relative and which components it includes must be established from the producing code.
The displayed values are generally close to unity, with more pronounced departures in some low-transverse-momentum bins. Closely spaced annotations at low momentum overlap, so the machine-readable bin content is required for quantitative use.

\subsection{Application conventions}

For a simulated event passing the analysis trigger selection, the intended correction multiplies the non-trigger event weight by the year- and channel-specific SF evaluated at the selected lepton momenta. One must not additionally multiply the event by the measured trigger efficiency when using this data-to-MC ratio prescription. The final deployment must document the validity interval, object selection, trigger OR, bin edges, boundary policy, and nuisance-parameter correlations. No release recommendation is made before these checks are complete.
