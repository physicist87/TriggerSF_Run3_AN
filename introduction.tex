\section{Introduction}\label{sec:intro}
Trigger requirements can select dileptonic $t\bar t$ events differently in collision data and simulation. To correct this difference, the trigger efficiency is measured separately in data and simulation after the offline selection used by the CP-violation analysis. The resulting ratio is applied as an event weight to simulated events in the $ee$, $e\mu$, and $\mu\mu$ channels. The measurement follows the MET-reference approach used in the Run 2 trigger note~\cite{run2}; the Run 3 data and trigger candidates are taken from the Purdue study~\cite{purdue}. The nominal offline selection here is that of the CPV analysis, including a jet veto map and a medium UParT $b$-tagging working point, and must be validated against the implemented Run 3 analysis code before numerical results are finalized.
