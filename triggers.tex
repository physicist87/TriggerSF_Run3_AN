\section{Trigger paths}\label{sec:triggers}
For each final state, the signal-trigger decision is the logical OR of the applicable single-lepton and dilepton paths. Table~\ref{tab:signal} lists the Run 3 paths shown on slides 6--8 of Ref.~\cite{purdue}; every path must be checked against the HLT menu and NanoAOD branches in each period. A recorded event may pass several paths but enters each numerator once. Any run-dependent changes, prescales, dataset-overlap removal, or trigger-object matching requirements must be documented before finalization.

\subsection{MET reference triggers}\label{sec:reference}
Events for the efficiency denominator are recorded with a logical OR of MET or MET+HT reference paths. These triggers select events without directly requiring an electron or muon. The reference set transcribed from slide 9 of Ref.~\cite{purdue} is given in Table~\ref{tab:met}. The unprescaled status and validity interval of each path, and its actual NanoAOD implementation, must be verified. The MET requirement of the reference trigger can bias the measured efficiency if it is correlated with the dilepton trigger; this assumption is examined in Section~\ref{sec:corr}.
